== Getting Started: Environment Setup

To begin, you need to prepare your local terminal (in the right-hand panel)). We have provided a repository containing all the necessary YAML manifests, scripts, and configuration files you will need throughout this lab.

Focus on your terminal and run the following commands to clone the lab repository and prepare your workspace:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
# Clone the official lab repository
git clone https://github.com/manuvaldi/techday2026-virt.git ~/techday2026-virt

# Navigate into the working directory
cd ~/techday2026-virt/manifests
----

Once your repository is cloned and you have successfully logged into the OpenShift Web Console, you are ready to proceed to the next section.
