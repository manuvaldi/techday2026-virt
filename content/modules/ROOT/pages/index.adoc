Welcome to the afternoon Virtualization Workshop. As organizations look to modernize their infrastructure, managing virtual machines alongside containers has become a critical requirement. This hands-on session is designed to help you explore and understand modern virtualization strategies using Red Hat technologies.

== Workshop Objectives

In this guided session, you will get hands-on experience with Red Hat OpenShift Virtualization. By the end of the workshop, you will know how to:

* *Deploy and Manage VMs:* Create, configure, and scale virtual machines natively within a Kubernetes-based platform.
* *Unify your Infrastructure:* Manage both traditional virtual machines and modern containerized applications from a single console.
* *Execute Migration Strategies:* Use built-in tools to migrate traditional virtualization workloads into OpenShift.

== Prerequisites

To participate in the hands-on labs, please ensure you have the following:

* A personal or corporate laptop with Wi-Fi connectivity.
* A modern web browser (Chrome, Firefox, Edge) to access the cloud-based lab environments. 
* _No local software installation is required._
